# Código de conducta

Este proyecto adhiere al [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: tratá a todas las personas con respeto, sin acoso ni discriminación; discutí ideas,
no personas; y aceptá con buena fe las críticas constructivas.

Para reportar un comportamiento inaceptable escribí a **devops@colossuslab.org**. Los reportes
se tratan de forma confidencial.
