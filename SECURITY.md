# Seguridad

Si encontrás una vulnerabilidad o un dato sensible publicado por error en este repositorio,
**no abras un issue público**: escribí a **devops@colossuslab.org** con el detalle.
Respondemos dentro de los 5 días hábiles.

Este proyecto no maneja cuentas de usuario ni datos personales; la web es estática y se genera
a partir de datos públicos.
